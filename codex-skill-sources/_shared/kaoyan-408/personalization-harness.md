# Retired personalization harness

This harness is retired from the current-question hot path. It remains only for
read-only compatibility with one explicitly named historical object and its hashes.
New learning and formal closeout must not call old personalization corpus/index,
selection, begin/finalize, linked-practice or background-report routes. Historical
objects are never rebuilt or rewritten to adopt current rules.

Current teaching uses the bounded committed-source `exam_tutoring_context_408.py`
query after independent current-question judgment. The display-specific transaction
uses `morning_campaign_turn_408.py` or legacy `managed_408_current_turn.py` under
`runtime-contract.md`. No legacy transaction or template requires a pre-answer slice.
