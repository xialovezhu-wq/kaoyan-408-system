# Bounded formal-intake reads

The root owns semantic decisions and every write. Ultra uses native orchestration;
this reference does not fix a child model, count, effort, fork mode or service tier.
Non-Ultra uses the existing orchestrate route only for substantial independent work.
When a user explicitly requests Luna, use a supported Luna configuration and provide
one frozen package SHA, allowed roots, one query and return fields. The leaf is read-only,
allocates no ID, invokes no transaction and starts no child. The root verifies evidence
and integrates once; conflicts remain unresolved rather than being decided by vote.
