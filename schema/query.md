# LLM Wiki Query Schema

本文件规定 408 LLM Wiki 查询时的读取顺序、输出边界和沉淀规则。

## 默认读取顺序

1. 先读 `wiki/index.md`，判断查询类型。
2. 涉及正式错题节点时，先读 `wiki/coverage/408-COVERAGE-001_正式错题全量覆盖索引.md`，判断相关节点是 `compiled` 还是 `formal_source_only`。
3. 再读相关 wiki 页面：`concepts/`、`topics/`、`error_patterns/`、`relation_summaries/`。
4. 若 wiki 未覆盖，再读既有 `概念词典.md`、`专题链/`、`知识体系/`。
5. 涉及正式错题关系时，再读正式表：
   - `节点总表.md`
   - `关系边表.md`
   - `知识点命中索引.md`
   - `错题日期索引.md`
   - 必要时读 `错题复做记录.md` 和 `复习单元总表.md`
6. 涉及历史题定位时，必须读：
   - `历史错题归档/定位规则.md`
   - `历史错题归档/定位索引.md`
   - 必要时读 `历史错题归档/正式ID映射.md`

## 查询类型

| 查询类型 | 主要入口 | 输出重点 |
|---|---|---|
| 概念解释 | wiki concepts / `概念词典.md` / `知识体系/` | 概念边界、常见混淆、防错提醒 |
| 专题复盘 | wiki topics / `专题链/` | 复盘顺序、典型错因、相关节点 |
| 错因模式 | wiki error_patterns / `错因标签表.md` | E01-E10 触发场景和防错动作 |
| 关系查询 | `关系边表.md` / `知识点命中索引.md` | 强/中/弱关系、推荐原因 |
| 复做推荐 | `错题日期索引.md` / `复习单元总表.md` | 7 天外候选、到期单元、评分需求 |
| 历史定位 | `历史错题归档/定位索引.md` | 历史 ID、定位标记、段落号、来源位置 |
| 安全节点卡片查询 | `DS/CO/OS/CN_*.md` / `节点总表.md` | 安全题目摘要、关键题设参数、问法类型、错误入口、复做第一动作 |

## 复做保护

输出错题、旧题、历史归档题、强关联旧题回顾或复做推荐时，禁止输出：

- 标准答案
- 正确选项
- 错误答案
- 用户此前错选项
- 选项字母组合
- 会直接暴露答案的信息

如果来源位置中含答案信息，输出时保留定位路径、定位标记和段落号，将答案相关片段替换为“答案信息已隐藏（复做保护）”。

## Wiki 沉淀规则

有价值的比较、关系综合、概念辨析可以沉淀到 wiki，但必须满足：

- 只写压缩后的概念、模式、关系原因和复盘策略。
- 不写完整题干、完整解析、答案或图片。
- 不直接变成正式节点或正式关系边。
- 若需要进入正式关系网，必须回到 `schema/ingest.md` 的 formal-node 流程。

正式节点查询时，如果存在同名安全节点卡片，优先用它恢复复做上下文；如果卡片为空或缺少安全题目摘要、关键题设参数、问法类型、错误入口、复做第一动作，应报告为待修复，不要假装该节点可直接复做。

沉淀入口：

- 概念辨析写入 `wiki/concepts/`。
- 专题路线写入 `wiki/topics/`。
- 错因模式写入 `wiki/error_patterns/`。
- 关系综合写入 `wiki/relation_summaries/`。
- 值得后续整理但暂未成页的查询，先登记到 `wiki/queries/查询沉淀索引.md`。
- 每次把正式节点写入 wiki 页面后，应同步更新 `wiki/coverage/` 中对应节点的覆盖状态。

## 输出口径

- 区分正式节点 ID 和来源 ID。
- 历史归档 ID 只作为来源定位入口。
- 关系类型只能引用 R01-R09。
- 错因标签只能引用 E01-E10 或“暂无明确错因”。
- 不确定时写“待确认”“待补充”或“本地资料未找到足够直接依据”。

## 可复制提示词

```text
请按 408 LLM Wiki query 流程回答这个问题。

先读取 wiki/index.md、wiki/log.md、schema/schema.md、schema/query.md。
如果 wiki 页面已有覆盖，先从 wiki 回答；如果涉及正式错题关系，再读取节点总表、关系边表、知识点命中索引、专题链和错题日期索引。
如果涉及历史题定位，必须读取历史错题归档/定位规则.md 和 历史错题归档/定位索引.md。

输出旧题、复做推荐或强关联回顾时，必须执行复做保护：不输出标准答案、正确选项、错选项、选项字母组合或任何直接暴露答案的信息。
如果发现同名安全节点卡片为空，列出空白卡片并提示用户补截图或来源，以便补成安全题目摘要卡。
有价值的概念辨析或关系综合可以建议沉淀到 wiki，但未经我确认不得写正式节点或正式关系边。
```
