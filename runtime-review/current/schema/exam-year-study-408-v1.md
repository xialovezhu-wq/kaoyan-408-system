# 408逐年真题学习与晨间年份隔离 v1

## 身份与存储

用户指定一天做哪一年真题后，在 `.private/exam-year-study/plan.json` 的 `daily_plans[YYYY-MM-DD]` 登记 `exam_year`、`status=planned`、`source=explicit_user` 和原话/会话来源，日期使用Asia/Shanghai。从 `required_from_date` 起未登记的目标日期停止出包，不自动递增年份、不复用昨日年份，不把例子当承诺。改计划保留旧版本并重新导出；已准备未开始的旧包重新校验，不重放学习或覆盖原包。

年度热记录：`真题年度学习/<年份>/学习记录.json`（机器索引）和 `学习记录.md`（可读归纳）。每年一个独立会话；后续同年份复用，跨年份新开。用户真实重做新增attempt，保留首卷。每次attempt记录实际日期、卷版本/来源、总分与分母、分科得分、评分依据（用户自报/卷面明确/教学估分分别标明）、耗时、原始作答附件、逐题EXAM408身份、完整Capture链接、真实首答、首个断点、提示后变化、专题归纳及未验证边界。缺数据为null，不填零，不凭导入/展示/讨论判已做。

用户已授权年度会话逐题复盘与快速保存。沿普通question-worker专题讲解；每题明确结束后用wrong-intake原生完整消息Capture，不需逐题重复请求保存授权。完整原话/图/附件必须保全；Capture成功后再把ID、路径和原始日期绑定年度索引。摘要不是原始证据。原题真题身份准确绑定，题库已有题不重复导入。年度汇总不是正式知识点概况，不能取代或提前调用正式判分、FSRS、掌握度写者；网页增强回流仍走原生入口。

## 做完一套卷后的薄弱点代表题

此类专项只排除明确保留年份的真题及直接暴露其答案的前置结果。其他年份的相同考点可用，原卷也可参与逐点日期比较。每个实际弱点先取已知满14天的候选；若无则取无记录候选；若全部为近14天，取最近真实接触日最早者。覆盖需要决定题量，至多30、可以不足。下节所述主兼考点整体隔离和到期名额适用于常规D，不是此专项的条件。

## 常规D的年份隔离门禁

同一天晨间复盘发生在计划新卷之前。先从权威 `support/syllabus-2027/point-question-links.json` 取得计划年份全部父题及小问，收集其 `assessed_points` 和 `primary_point`（主考、兼考）。没有完整映射则不放行。`prerequisite_points` 与 `context_only_points` 不冒称主考/兼考点；不能用泛科目或章节字符串代替已核考点。

候选若属于计划年份，或其精确身份所考任一主/兼考点与年度集合相交，则拒绝。不能只看本次复盘锚点concept_id：候选兼考点也必须核。小问用自己的映射，不能把兄弟问无关考点硬套入本问；其提供前问结果的contact_dependency_ids也要校验，避免通过已知输入预先复习禁区。题面、解析、teaching、轻微拓展均受当前隔离范围约束；允许题不能顺便教授受禁考点，也不能用别名或其他年份同点题绕过。

导出先过滤，再算高频层、目标数量和小问实际可供数；之后仍执行14天真实接触、近期错误相关、每主点一题、父子和给定答案冲突。不足30据实交代，不改写为全额完成，不填补冲突题。年度隔离优先于数量与频次。

输入随包保留年度排除快照及哈希；回包须保留绑定。接收时读取最新计划重新核对，旧输入不能绕过新增计划。未开始交接首次开题前再次校验实际学习日期计划；已开始若新计划冲突，保留原序与已保存证据并hold，不能以更新计划重排/重展示。改日期须按实际当天重核。

## 校验记录与网页协同

本机 `真题年度学习/校验记录/<日期>.md` 保留状态和T9完整报告入口；机器状态位于 `.private/exam-year-study/`。T9冷报告保存原包SHA、输入版本、计划SHA、知识点映射SHA、逐题允许/拒绝及原因、前问依赖、最终数量、发布快照及网页设置保存/读回状态。新冷产物先check-output，结束register并读回；原ZIP和旧备题成果保留。

网页晨间项目只用本批绑定年份与排除集合备题，不自行猜年份。网页知识库/年度学习项目按年份记录真实学习，向晨间交接时附明确目标日期与计划年份。项目固定说明、本地指令源及只读Study Library发布资料同版；本地文件更新、发布快照可读、网页设置保存是三个不同验收事实。

## 明确日期的考点补位与优先级例外（2026-10-26）

默认年度考点硬排除保持。只有当天plan的`morning_point_overlap_policy`含受支持policy、`source=explicit_user`及真实用户原话时才启用考点重叠。计划年份原题、独立小问及直接提供该年题答案的前问依赖始终硬禁，例外仅允许其他年份的同考点题。

2026-10-26用户最新明确选择“高频优先，允许重叠考点补位”。当前模式`high_frequency_then_nonoverlap_with_other_year_fallback_v1`按频次层优先，同频次内非重叠优先：非重叠高频→重叠高频→非重叠中频→重叠中频→非重叠低频→重叠低频；仅涉及、未知等保留原频次标签。全部合法高频用尽前不能选中低频，不得因中低频不重叠而挤出仍合格的重叠高频。每个频次/重叠格在更高优先级已选题的约束下核验真实可供容量。

旧模式`prefer_nonoverlap_then_fill_other_years_v1`仍可读取原登记合同：先用尽所有非重叠频次层，不足目标数才补其他年份同点题。该模式不能覆盖新的明确日计划；旧输入和旧规则保留用于溯源，不静默改写。

两种模式均守14天真实接触、近期真实错误关联、每主点一题、唯一题面、父子/给定答案冲突及独立小问合同。小问按现行规则在同频次内预留，不能用低频挤出高频；确有来源不足如实报告，不造题或放松曝光。

候选携带`exam_year_selection_stage`（0非重叠、1其他年份重叠）与`exam_year_point_overlap_policy`。selection-contract绑定当天排除哈希、`exam_year_point_overlap_policy`和`annual_stage_capacity`；新模式的容量审计按频次/重叠格列实际容量和选择数量。导出、回包和首次开题都从登记候选池重核，不信网页自行标的层级。

新模式首次开题必须核验所有队列的原生`selection_input_version`、最新日计划哈希和优先级，即使旧队列全是非重叠题也不能跳过。因此先前生成的旧模式Oct26输入保全但须重备，不能继续交付。已有active/paused沿原展示/保存身份，不重排或重放；实际计划/新真实接触变化均在未开题门禁重核。
