# 408 当日正式收尾

「将今天快速入库的题全部正式入库」授权本机在同一任务顺序完成正式编纂、错题讲解读回、真题预处理和复盘 HTML。用户发来的会话、附件或年度学习记录用于核原话、题源与做卷范围。全量以当天快存账本为准，包含其他聊天中的同日 Capture、正确题、复做和纯考点讨论。使用 Asia/Shanghai 原学习日；跨零点恢复沿原日期。单题、精确集合、累计截止日、仅补某项等明确范围沿各自入口。

## 正式入库和错题讲解

1. 用 `python3 scripts/runtime_paths_408.py --run intake_fact_capture_408.py --repo . backlog-plan --cutoff-date YYYY-MM-DD --only-today` 查当天账本及旧回执。核对完整原对话、必要附件、已有正确终态和补充链。每条应处理的 Capture 绑定实际正式终态或待办原因。空写入集合时先查该日是否已正式完成，有原结果就用它继续缺失的交付；当天确无快存则报告没有可处理证据。
2. 新有内容的批次走 [enhancement-intake](../../kaoyan-408-enhancement-intake/SKILL.md) 与 `<repo>/schema/408-formal-quality-v1.md`。真实 OpenAI embeddings 在合规全库找资料和关联，Decisions 核查候选条件及实际终稿，凭据绑定冻结原件、本批和 prepared SHA。只发送合同允许的去标识机制材料。经唯一写者提交并验回全库向量路由、受影响个人概况、题级教案与同版本机读回。
3. 个性化摘要落实到个人已成立步骤、第一处断点、仍缺的条件或独立检查、讲解切入和图解着重位置。父考点与 KSP、概况与短摘要及 `next_check` 同步。由 `apply/status` 核对所有受影响记录，另对本批更新的代表性精确题或 Pxx 直接按 [question-worker](../../kaoyan-408-question-worker/SKILL.md) 的 `resolve --current-question-id ... --personal-scope full --materials core` 验回 `personal_read_receipt` 和新摘要，图解按需用同一 `source_version` 查 `--materials visual`，核对真实字段、方向或状态和 `protected` 隐藏。来源暂缺或只证明提示后修复的条目保留真实状态。正式写入、讲题读回和两个学习交付分别记录验收结果。

## 交付一：错点真题专项

本机质量回执通过即可继续两项日终交付。只有用户明确要求远程访问或外发时才发布 Study Library 副本，副本不计入本机两项交付的完成条件。

- 从当天原答、理由、实际断点和原图提炼窄机制；答对但理由有真实错误的纳入。多个题暴露同一错误合并，父标签和无独立依据的掌握推断不当作错点。
- 当天学习的主卷年份明确时，保护其下一年度。当天学的是 2015 年真题，就硬排 2016 年原题、独立小问及直接或间接给出该年答案的前置，即使当天只学了 2015 年卷的一部分。叠加用户明确保留的其他年份及原学习日、备题日、开题日的已登记保留年。其他年份相同考点照常比较。当天明确学了多套主卷时，把各主卷的下一年加入 `excluded_exam_years`；零散混合且无明确主卷时沿用户明确保留年，来源题号未知时保留空值。
- 走 [morning-control 的日终错点专项](../../kaoyan-408-morning-control/references/local-preparation.md#当日正式入库后的错点专项)，复用 `annual-sources`、`annual-prepare`、`next`。全库核对实际考法后按每个错点原有年度专项接触优先级择题。每点优先一题，有不同操作或边界才加第二题；同题共同代表多个错点时总量只计一次，每个实际采用的错点均计一次。总量至多 30 道，遇到题源、匹配、资格或总量限制时写明缺口。确无真实错点或合法题源时交零题结论与依据。
- 实际预处理原题图、独立小问完整已知条件、私有讲解与分阶段机制图。验回 `PREPARED_NOT_STARTED`，确认 `prepared_visual_question_count` 等于最终题数，核准每个错点的代表依据、保留年检查和真实 `START_STUDY.md`。用本题分阶段读取入口检查成品能直接取用；只读预检不记曝光，等待用户以后提出开始。

## 交付二：当天交互 HTML

走 [evening-review 的全天交互阅读](../../kaoyan-408-evening-review/SKILL.md#当日正式入库后的全天交互阅读)。以同版当天原件和当前摘要为依据，覆盖实际讲过或核对过的知识点，包括正确题。按机制合并，写定义、关键条件、判断入口、有依据的二级结论及其适用边界；以目录串起全天，视实际关系用可点对象、时序步进或对照图。选题是错点练习，HTML 是当天知识内容的整体阅读，两份独立可用。浏览器后台核对读卡、图解互动和需要的备注操作，交实际 `review.html` 链接。未来卷和未公开小问答案不进入网页源码或数据。

## 读回与续办

以原日期、范围与本机来源版本在经核验的 T9 当日工作区保留一个接续记录，指向已验证的原 prepared 回执、题集和 HTML，说明仍缺哪一步。完成时重查当天 backlog，单列新增或未能终结的确切 Capture，沿原事务补缺。题集或 HTML 遇到缺项时保留已通过的正式结果与成品，继续补该项。最终回复简述当天入库及讲题读回状态，附可开练题集和复盘网页；确实未能完成的环节列具体原因和现成入口。
