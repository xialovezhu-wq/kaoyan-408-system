用于证据冲突、复杂Pxx边界、新图制作或特别核验。常规热路径以SKILL.md为先；质量与答案保护规则保留。不要每题重读本文件。

# 408 单题讲解

使用用户在当前对话选择的模型。按[408 聊天重点显示](chat-formatting.md)给本步条件、动作或结论。默认 `visual-first-408-v2`，优先展现一张对应真实断点的可点击机制图。局部追问在正文讲清本步条件、对象变化与原因，保留单位。用户要全文时，在正文给齐本问必要推导和结论；同源图用于观察关键变化。首段实质反馈沿[本科时延口径](../../_shared/kaoyan-408/runtime-contract.md#讲题与快存的时延口径)记录。

- 备好的错点专项：保留 `next.teaching_context`，按获准的题号和阶段从同一交接读已预处理图解与题专教案。详见[备题交接里的预制图解](interactive-delivery.md#备题交接里的预制图解)。

模型负责语义判断；固定入口负责原始证据、幂等保存和导航。正常教学不读保存源码、help、环境、SQLite或会话日志，不另写适配/预检脚本。真实失败只按返回路径恢复；先给已核实教学反馈，保存未验证不得提前导航。

## 个性化摘要是必要输入

摘要与精确题教案来自同一正式闭环：快速Capture保存实际发生的讲解和反馈，正式入库由当前本地会话按本机固定版本历史、原考纲、当前题面和真题/教材编写修订，经原生写者提交、发布和读回。日常讲题以当前正式查询为准，不从项目记忆、未审核回包或旧预备稿覆盖它；`template_native_version`、`source_visual_plan_version`及路线原生版本只用于核对已生效对象，不是学习或效果证据。正式入库的写者见enhancement-intake，学习中不自行运行写者或重建全库。

1. 先结合题面和本轮实际作答，定位需要核对的具体机制，再用当前题绑定的规范代码和断点关键词读取最新 source_version 下的相关个人摘要；已有核实的KSP小点身份直接使用，不先完整讲题再补查，也不为定位摘要先扫描全库。有已核验题目身份时，同次带入当前精确题ID，取得顶层 `question_visual_template`；它是本题专用图解，知识点 `visual_template` 是补充依据。不能以通用知识、网页旧 history_summary 或预备教案代替个人摘要，知识点命中不等于用户弱点。
2. D 使用当前 input_context 的 d-supplement-context，传 view="after_attempt" 和必要的 teaching_mechanisms。一次同时返回 teaching_context、grading_reference、当前题 prepared_context.solution/teaching，完整读取相关摘要，不再另读答案文件或重复 resolve。明确直接讲解用 direct；未作答保护答案用 protected。
3. 同题同断点续用input_context中的teaching_mechanisms、known_version与known_material_version；新断点替换为本轮必要机制数组，明确回到父点传[]，不机械累加旧关键词。unchanged分别复用已读的完整个人摘要、答案、教案；仍执行来源与文件校验，不把版本未变当作无需校验。D v13校验缓存身份、视图和版本，缺缓存时完整读取；上下文已丢失旧正文则清空教学缓存，不以JS对象存在代替实际读取。保留本次缺失/歧义诊断，未命中的机制不能称已命中。纯“理解了／下一题”确认且答案理由已核实，无新教学判断时直接保存，不为收尾重复context；有新理由或疑问仍做本轮核验。不轮询版本、不预查下一题。
4. semantic_current 可用于当前个性化讲解；evidence_digest_only 只作事实。semantic_stale 按返回的具体对象和原因处理：个人方案来源失效时，不绕过查询隔离重用旧方案；仅题源、图解或教案失效时，只停用或重审该素材，不把仍经核验有效的个人理解证据一并判为未知。缺失、未命中、冲突未解或适用范围不明的环节保持未知，按本轮证据讲解并保留缺口，不换词反复查库或现场重建。
5. 先由现有输出约定、当前提示级与答案保护决定可展示内容，再用有效摘要决定解释粒度。在内部将相关摘要对应到当前路线的主体、处理对象、分支条件、状态变化及下一步所用结果，不新增对外固定栏目。某环节有明确理解证据且范围相符，保留已正确动作并浓缩说明；明确卡在某个机制或连接，只补该缺口及必要前置，再回到主线。只会术语、选对选项、看过讲解或点过图不证明机制理解、独立计算或迁移；本轮明确说某步不懂，就调整该步，不被旧摘要挡住，也不扩大为整个父点不熟。压缩重复说明不取消原本必须交付的图解。正文不播报摘要字段或重复历史；只有用户问历史或有助于当前纠偏时才展示具体记录。链接用返回的 records/questions 的 markdown_link 或本地HTTP桥 open_url，不猜链接、不输出裸 Obsidian URI。
6. 返回 `teaching_plan` 时，将它作为具体机制的备课线索：`learner_entry` 保留用户已有的起手直觉，`first_breakpoint` 指出当时第一处断点，`first_action` 决定本题先圈、先分或先追哪一个对象；`explanation` 和 `visual` 决定解释桥梁与图中突出部分。先与当前作答对照，只用仍相关的一段；不能把旧断点直接宣判为今天仍不会，也不向用户逐项播报这些字段。尚未作答时服从 protected，不用计划泄露答案。
7. 解释策略与效果分开：`proposed_only` 只是建议；`user_reported_helpful` 只是本人反馈；`prompted_repair` 只支持原回合的提示后修复；`independent_transfer` 仅限绑定证据里的独立情境。原来文字解释后答对，不证明新画法已有效。`pending_capture_teaching_only` 仅供本轮教学选路，不覆盖正式摘要的掌握结论、学习日期或FSRS。源变动按对应对象处理；分页或预算省略不等于没有记录或偏好。省略部分确会影响本轮判断时，在既有预算与披露边界内沿返回的同版精确引用或游标补读，不扫描原对话或全量历史补计划。
8. 返回 `visual_template` 时，先选定当前断点对应的机制，再从模板抽取所需部分：`scene` 提供对象位置、连接与方向，`steps` 提供相关状态顺序，`checks` 核对条件和边界；`personal_adaptation` 与当前小点摘要共同决定突出哪一处。这些字段不是必须逐项展示的学生步骤。静态关系可点击核对角色和关联；确需比较前后状态时才增加步进。先显示本轮需要的核心状态，不把整道题或整个父点全部画出。KSP 返回 `scope=subpoint_specific_visual_override` 时采用该精确小点配方；返回 `parent_template_adapt_to_current_subpoint` 时才收窄父模板。配方须结合当前题编译，不代表已有页面或已验证效果。
9. `visual_template` 是参考资料支持的讲解方案，`effectiveness=unverified` 不代表已经对用户奏效。它与有真实会话证据的 `teaching_plan` 配合使用，不覆盖后者的真实断点与证据强度。`protected` 不公开模板的解题状态或终值；读取失败时按当前证据选择最小图解，并如实保留个性化缺口。实质机制讲解交付前检查：首屏是否能看出当前对象、条件和变化，以及同轮是否交付对应的可点击界面。源码、图名、路径以及承诺稍后画图都不算图解交付；文字和界面分别核实，界面失败保留已成功文字并只修显示层。简短核对、保存导航及用户明确纯文字请求沿原例外。
10. `question_visual_template.status=reviewed` 时优先按本题 `given_objects`、`initial_state`、`target` 建立画面，沿 `scene/steps` 演示当前断点，结合 `solution_anchor/checks` 核对参考机制。`adaptation_rules` 用当前真实作答和同次个人摘要决定突出哪一步，不把模板里的条件分支当成用户已经犯错。只讲当前允许的步骤，答后仍服从当前提示层级；模板包含正确结论不意味着必须直接揭晓。`source_limited` 仍可按已核实条件展示可用的机制图解，同时明确缺失条件或来源冲突，不强给唯一结论、不冒称完整审定；`missing/stale/unavailable` 不冒称命中本题模板。
11. 父题、`EXAM…-Pxx`与章节私有教学分段是不同身份。小问只读当前小问模板，不能用父题或兄弟问替代。父题答后返回的 `parts` 只用于精确导航；`part_id` 是本地编号，只有有来源支持的 `source_part_label` 才是原题分问标签，不能把“原题第二问”自动当作 `P02`。现有章节题的私有 `父ID#P01` 仅用于教案定位，保留原文分问标签，不是新增正式题或学习记录。已给前问结果按模板的 `prerequisites` 区分原题已知与参考解补充，不将后继问答案带入本问。只有截图而身份未核实时，先按已知题库来源核对题面和参数；不得仅凭相同知识点、年份或选项猜题ID。
12. 同次返回 `teaching_plan.visual_feedback` 时，用其scope与当前机制核对：从个人反馈选择形式、布局、讲解粒度和步进，题设参数及正确性边界仍以本题核验依据为准。preference是偏好依据，observed_effect是效果依据，二者不能互相升级；comparison及next_adjustment给出上一版的具体问题和下一次尝试。用户当前明确要求优先，不把旧偏好变成所有题唯一画法。无新证据可沿用，不为“不断进步”机械换图。模板/成品版本没有真实记录就保留未知；这次使用了一个新版本也不能立即称已有效。超预算时读取返回的完整方案证据对象或使用短摘要里明确保留的要点，不把省略当作没有偏好。真实反馈按当前保存合同随完整对话和实际成品保留，正式偏好更新留给入库，不在教学中另写长期掌握记录。

普通单题尚未取得必要摘要时，一次调用：

```text
python3 scripts/runtime_paths_408.py --run exam_tutoring_context_408.py resolve --repo . --concept '<绑定规范代码>' --mechanism '<实际断点关键词>' --view after_attempt --personal-scope teaching --materials core
```

多点可重复传 `--concept` 或 `--mechanism`。已有 KSP 直接用其身份，只有正式 ID 时用 `--formal-id`。核对 `personal_read_receipt` 和 `omitted_*`，按 [个人摘要引用规则](personal-learning-context.md) 在确有需要时完整回读同题同机制。已有精确归档定位且需原件时读 [单包重开](archived-evidence-reopen.md)。图解需要时按同一精确身份、机制和 view 读 `--personal-scope full --materials visual`。

精确题ID、规范代码或KSP已知时直接走本机原入口。只有自然语言机制描述时，用memory discover --intent concept查本地候选，再依据当前题面核对并resolve；找旧作答/说法用--intent experience --actor user，找助手解释用assistant，再沿trace_request核源。保留现有题目/机制/年份/allowed范围，不能为取得原话取消限制。经历摘要不充当逐字原话，最近候选不证明全历史最后一次；具体view与原回合限制见统一memory合同。未命中则结合当前证据继续，注明个性化范围。常规讲题无需 Study Library 连接、付费 Embeddings或远程回传；默认后端由共享合同的本地资格策略决定，精确身份、经历及保护边界不变，reranker未默认；不把资格结果外推为所有查询准确。候选只作定位，不能据相似度推定弱点、产生正式关系或预读后继题。

已核验当前题身份时，在同一次 resolve 加 `--current-question-id '<精确题ID>'`（兼容真题 `--exam-question-id`）；只有正式节点ID时可用 `--formal-id`。明确只讲章节教案的一个私有分问时加 `--question-part P01`，原真题 `-Pxx` 仍直接传完整原ID。只传当前精确题ID也会补齐所需个人摘要；有明确小点则继续传KSP或机制，返回局部摘要与本题模板。不是真正当前题的关联原型不能放入当前题参数；D/campaign已经提供当前身份时复用，不另外猜定。仅在用户点名 MCP 接口时，共享 Study Library 的 `personal_context` 在 contains JSON 中接受 `current_question_id`、`current_question_part`、`formal_id`、`source_id`；必须核对同版freshness，预算不足依minimum_bytes补齐而非把空结果当无资料。

共享查询返回 `next_cursor` 时，保持相同 `source_commit`、当前题身份和view，将游标放入 contains JSON 的 `cursor` 继续到 `complete=true`。逐题模板和个人摘要可能分在不同页，不能只读第一页就声称两者齐备；无须重新查询已完整读到的同版内容。`grading_policy.allowed=false` 时保留题源的判分限制，仍可按明确条件讲机制，不自行把有争议的唯一选项用于评分。

## 将摘要、文字、图解接成同一条解题路线

本题采用教材及原卷实际模型，不主动加入题目无须的特殊架构反例并当作个人弱点。解析出现冲突时区分原题图、原文解答和教材定义，按来源与独立推导裁决，原件保留。

同次返回的 `lesson_bridge` 是教师组织线索：精确题优先 `question_visual_template.lesson_bridge`，点/小点桥接只作补充。它把文字步骤、局部图配方和有来源的相邻考法接在一起；先与本轮首答、范围和提示权限核对，再取需要的部分。候选不自动成为课堂内容，桥接对象不直接进入前端。`linear_teaching_route.current_teaching_brief` 与 `teaching_plan.interaction.personal_adaptation` 提供相关个人适配依据，不能把偏好字段画成学生节点。先核对本问目标、地址/编号/单位、给定前置与真实首答；明确要求优先于历史倾向，unknown不猜成喜欢，observed_effect不由preference升级。

从用户的第一处断点起步。首屏把条件与它决定的动作或状态并列呈现。图中对象、关系和单位沿原题。在已授权的推导区保留完成解题所需步骤。

中文优先说清具体主体对什么对象做什么，并区分先后、数据流、条件分支与因果；不能把“随后发生”写成“因此必然发生”。判断保留合法性、权限、边界及题设模型，多个对象并存时消除指代歧义，正文、图与题设使用一致名称和编号。标准术语保留，只有它阻碍当前理解时才解释其角色；已清楚的表达不机械加定义或成对关联词，也不编造更底层的实现。图前明确起点、关注对象及箭头/高亮的含义，变化条件与正文对应，图后接回下一步；图的播放阶段不等于整题推理步骤。粒度与图示说明的具体例子及研究边界见[从原话到讲题图解](dialogue-to-visual.md)。

“贴考纲”包括已掌握与未掌握的详略分配，以及有依据的知识结构联系。先按当前作答与有效 `teaching_focus` 的具体机制处理：独立说明过且本轮仍成立的动作简带；明确缺口重点解释；提示后修复只压缩已修复部分，未独立验证的边界保留。没有此字段时读有效摘要作有界判断，不从字母答对或关键词自动推掌握。本题主线解决后，检查同版 `syllabus_context.teaching_boundary`、`lesson_bridge` 和已核验真题考法，在同点区别、考纲上级、下级及经审核关联中选最贴近的一至两个联系，优先高频目标。用一句关系说明接回本题，再说明真实题目考过的条件或所求；高频点在本题下级时应主动检查该连接，不能只因旧方案 `none_by_default` 就漏掉。目标须同时纲内且有具体真题依据，只有大章相同、名称相似、资料拓展表或预测题不够。当前断点未解决、提示权限不允许、年度隔离冲突时不展开；不串讲整章、不重出近14天原题。具体决策见[考纲与真题约束下的讲题流程](exam-oriented-teaching-flow.md)。题面决定参数和所求，教材提供机制，真实对话决定解释入口；不能把旧题数值或算法约定带到新题。`needs_review` 只用已核验父范围，不冒称小点已独立审定。

## 根据当前真实回答讲解

分别检查答案与已展示理由，先保留正确步骤，再纠正第一个有证据的对象、条件、边界、单位或时序断点。不补造推理、错因或掌握度；省略非必要步骤不当成错误。这些判断决定文字从哪里接续、哪一步放慢、图解突出什么；详略服务当前断点，不默认套固定长篇格式。

- 答案和理由充分：核实后简短反馈，同轮完整保存。已发反馈由真实消息入口封存；不预称保存成功。
- 只有字母：只问一个关键理由并等待，不封正确。D由终态统一收全对话；campaign按其 discuss 合同保存草稿。
- 字母正确但理由错误，或仍有必要缺口：局部纠偏，只问一个推进问题，等待。明确“不懂”不补造首答；明确直接讲解则直接讲。
- 提示后完成与独立完成分开。明确结束用 end/unresolved 并 hold；跳过用 skip，不伪造答案；暂歇不封终态。

每轮最多一个推进问题。不为机械复述或统一格式追加提问；是否终态取决于真实理由。讲解中的新事实也不能写成用户自己说过的话。

主考采用选择题或已审核独立小问的主考点，并按父题去重；综合题父题原主标签只作入口，不额外贡献主考次数。阈值沿同版统计，不在讲题时自行改级或以总考次替代主考次数。每题首次答后反馈或直接讲解，用 question_exam_introduction.primary_intro（或 introduction_text）简述考点、统计范围、总考次、主考/兼考和频次等级，作为原有文字开场。明确说出来源标注的高频/中频/低频等级，不能只给年份、次数或“重要考点”；“简短确认”“只问局部”不构成漏报理由。只有本题已在当前对话实际输出过这段开场，后续追问才不重复；已查询、预生成或在其他题讲过不算已输出。用户只要图时可放入图中，不挤占主图；protected仍沿既有隐藏规则，不借考频提示答案。它绑定当前 true_item_id；没有题级开场才用核心点 frequency_intro。缺失或未标注时明确说明“考频数据暂不可核实”或来源原标签，不猜次数、补算等级，也不把未知、仅涉及、样本未见考查当作低频。父点统计必须点明父考点，不能当成KSP考次，高频不等于个人弱点。交付前核对本题开场已实际出现，或已明确报告数据缺口。按同次 syllabus_context 的2027路径和 teaching_boundary 限定解释，必要前提补足，out_of_scope不展开，needs_review不冒称已核验。

## 题面与机制图解

先按当前真题原图分析，选对本步机制。优先使用 `question_visual_template.exam_visual_binding`：`source_assets`区分题设图、解析图和已给前问结果，`preserve`保留原图布局、字段、编号、连接和初态，`focus_by_step`指出哪个解题步骤需要突出什么。绘制时沿这些真实对象清晰重绘，不能把多重表改成圆环、把流水时间格改成概念节点、或省去硬件图关键线路。原题无图则明确为机制示意，不能借同知识点图冒充本题原图。机制图表现对象变化，必要条件、单位和本步一句因果随图呈现。

固定到历史原件的题级教师参考只保留其当时依据；题设事实仍由精确题核验，具体讲法以同次现行考纲、有效个人摘要及规范点/小点路线调整。不可把历史 `teaching_design` 中的旧边界或画法优先于这些当前输入。`source_visual_plan_review`明确退休的设计及口述不得回退使用，按本轮真图绑定重编；已有具体设计也须符合原图结构。已备配方数量不等于实际页面数量。

点级 `visual_template_status=source_visual_only` 只提供当前图源，表示旧个人适配已隔离；结合当前正式摘要与精确题重新编译，不补回旧scene/steps。已验证仅全局索引元数据变化的引用可沿精确重绑定使用，不把真正发生变化的个人依据当成未变。

晨间只用已准备的全部题图链接和真实来源；不 view_image、裁图、放大、OCR或修图，显示异常时回到本题已准备的本机原图或对应本地查看入口核对。只有明确要文字时才提供已有公开文本；不预解下一题。普通新题的图像理解不受此限制。只有正式ID而缺题面时，用一次 study_bridge_408.py question-source --formal-id <ID>，缺件不猜题。

首次或恢复展示冻结题目时，仍只交付真实来源和全部公开题图，等待作答；以下规则用于当前已允许的讲解与纠偏，不为未作答题提前补解题图。

### 从个人断点选择解释力最强的形式

图解必须回答一个具体理解问题，例如“页表项自身放在哪里，取出的内容又是什么”或“这条赋值改了局部指针还是结点链接”。图放在对应推理处，用与正文一致的对象名和条件；图前交代要观察的关系，图后用观察结果接续解题。已用一句话说清的计算或结论留在正文。若连续仍说看不懂，先检查对象、关系或前置是否缺失，不靠换色和添说明框掩盖断点。

| 当前需要看清的关系 | 优先考虑的可视化 |
|---|---|
| 谁执行、谁持有、谁通知谁；软件层与硬件、共享与私有混淆 | 主体分区或泳道图；把数据、命令、通知画成有方向的连线，明确运行代码的主体 |
| 时序、等待唤醒、窗口/缓冲/许可的变化 | 可步进时间线或状态演示；同步显示当前事件、占用/剩余量、等待者及前后状态 |
| 拓扑、寻址、内存布局、编码字段 | 拓扑路径图、分层结构图、字段/位段图；突出本次路径、边界和对应关系 |
| 代码语句与运行结果、P/V位置、局部变量身份 | 原代码高亮与执行状态联动；把语句对应到对象读写、许可变化和阻塞点 |
| 两种机制沿同一条件比较 | 并列对照图或对齐的状态卡；只在静态字段比较更清楚时使用简洁表格 |

实质机制讲解按[408 左侧 HTML 交付](../../_shared/kaoyan-408/sidebar-delivery.md)实际打开本题 HTML，右侧给必要文字和普通链接。点击突出真实对象、关系或状态，按机制决定是否步进或调参。渲染器只播放已经核对的状态。

### 机制图与必要文字

- 用文字说明“这道题从哪一步入手”：保留已做对的步骤，把第一个需要改变的动作及理由说清，沿本问目标向下推理；不把所有历史薄弱点一次展开。
- 用位置、分区、箭头、颜色、路径和状态变化承载关系；同一对象保持一致的名称与视觉标记。不能把长段文字塞进方框，或只放几个图标，就算完成可视化讲解。
- 动态图每次只改变一个已说明的事件，前后同时能认出对象去向。窗口图分开“容量范围、已发未确认、尚未发送”，缓冲图分开“哪块数据、占哪个缓冲区、哪个阶段可重叠”；避免一条箭头把这些含义混在一起。接线或所有权是卡点时先给结构局部，再演示时间步骤。按需参考[把原话断点变成可见图解](dialogue-to-visual.md)，不要求每轮读例子或套同一图。
- 给本步需要观察的关系及关键条件，图中直接突出对象变化。图中只保留辨认对象和局部核对所需文字，不复制整篇长解。后续追问优先复用原图并解释真实卡住的局部；每轮至多一个必要推进问题。
- 用户明确“只要图／不要文字”时，只交付图解及不可缺少的短标签；不另起文字长解，不强加图外问答。
- 当前任务的展示片段用原热目录及 SHA 校验，按侧栏合同生成独立 HTML。右侧文字说明本步判断，链接重开同一页。若宿主未打开，仅恢复显示层，保存结果与答案权限沿原回执。
- 数学公式、推导和解法对照仍遵守仓库原生数学排版，不能为追求视觉把公式改成图片，也不把长公式塞进表格。

### 教学与实时边界

- 文字和图解共同遵守答案保护、当前提示层级与考纲边界：完整文字解释只覆盖本轮获准内容，未公开答案、最终数值或可直接反推出答案的状态必须在生成前删除，不进入正文、前端数据、隐藏面板、DOM或可恢复状态；折叠不等于答案保护。after_attempt只允许读取教师材料，不自动开放全部答案。点击、看完动画或自述看懂不等于独立掌握；不因此跳过真实作答或修改评分。
- 已准备的晨间题图保持原交付方式；教学示意图是单独的解释，不重读、裁切、修补或替换原题图，不预解后继题。
- 复用已核实图形与数据，先给已核实且本轮允许的实质文字反馈，再在相应推理处呈现辅助图。日常复用已验交互渲染器，不启动浏览器、tldraw或截图流程；首次开发、显示故障或明确验收才检查真实点击、键盘及主宽度布局。实时新图仍遵守一次主宽度渲染与一次视觉检查预算。
- 单一事实核对、简短正确性确认、保存或导航可以直接简答；用户明确要求纯文字时照办。默认用紧凑机制图和必要文字，用户当前明确只要图时依其要求处理。

## 保存后交付

仅当 capture_verified 和 package_verified 都为true、next_action=present_next，才在同一条final中先给保存回执与刚结束题的核心短速记，再附简短进度、后继真实来源及全部 presentation_markdown，等待作答。速记按wrong-intake的统一标准提炼可迁移知识点、二级结论、适用条件及下次第一动作，原题数值答案清单不能替代知识速记。有明确视觉收益时，以简短文字配本问可点击机制图，公式保留正文。即使工具前commentary已说过，final仍须简短重呈，明确只记录不讲的限定除外。不重复长讲义，不追加查回执、看图、求解下一题，速记不越过当前-Pxx及已公开范围。hold不发后继。可选礼花仅沿已明确授权偏好，由固定助手一次执行，不因保存完成自行新增。
