# 考纲与真题约束下的单题讲解

本参考用于决定一题讲到哪里、哪一步需要图、何时展开同一考纲专题。查询、答案保护、保存与导航沿 `../SKILL.md` 的当前入口，不另起历史查询或讲题流水线。

## 证据各管什么

- 当前精确题面、附件和已核验参考确定条件、所求、正确机制；不能把同知识点旧题的参数和约定移来。
- 当前作答和已展示推理确定哪些动作正确、第一处断点是什么；没展示的过程保持未知。
- 同版个人摘要与 `teaching_focus` 决定备课重点：按有真实原话的具体机制区分 independent_demonstrated（简带）、explicit_gap（重点）、prompted_repair（提示后修复，按边界检查）及 unverified（不宣称已会）。哪些前提可以压缩，哪个历史断点值得检查，哪种解释值得尝试，都须服从该证据范围。它不能判定今天又犯了同一个错误。
- 当前 `syllabus_context.teaching_boundary` 确定可讲范围；`exam_frequency` 说明统计，不证明某种具体考法存在。考法需有可核对的题目身份、相关条件或所求依据。

每题首次答后反馈或直接讲解仍先给主Skill规定的考点/考频开场，明确来源等级或缺口；局部纠偏、简短正确性确认不省略它。只有当前对话已实际给过本题开场才免重复，不能用“没有小点独立统计”为由漏掉已提供且明确归属的父考点统计，也不能据父点等级给小点定级。

D/campaign 已返回当前上下文就复用；普通单题沿主 Skill 的一次 `resolve` 取得精确题、相关摘要与范围。同题按版本复用，缺失或漂移时按当前证据讲解并保留缺口，不在学习中扫描、修库或重建。

维护时用 `support/syllabus-2027/catalog.json` 的原纲条目、`context.json` 的规范点／KSP 范围和 `question-syllabus-map.json` 的实考映射核对四科入口。热查询只读精确 `question_scope`、选中记录与本题同版考频。再从同版 `local_syllabus_lessons` 或 `question_visual_template.exam_visual_binding` 沿精确题／Pxx 取得源图与解析定位；视觉标签、历史个人路线和候选扩展不决定实考集合。独立小问只读自己的已核条件资产和明确给出的前置结果。

同次返回的 `lesson_bridge` 汇合文字步骤、局部图绑定和相邻考法候选；有精确题时优先 `question_visual_template.lesson_bridge`，点/小点桥接只作补充。它是教师组织线索，不是待展示的学生文案。将它与当前首答核对，再选择本轮要保留、慢讲、画图或略过的部分；不把整个桥接对象或候选列表送进前端。

## 先完成本题主线

先定位本问在求什么，再用题面线索说明第一动作及后续路线。例如涉及地址转换时，需要先知道题目给的是哪种地址、按字节还是按字编址，再决定拆分字段、查找哪一级表、组合哪个目标地址。这里只选本题实际需要的步骤，不预设所有寻址题都包含TLB、缺页或多级页表。

已有正确路线就保留；只卡局部时从局部接续。文字按实际因果说明“为什么做这一步、得到什么、下一步用它做什么”，重要条件随相应步骤检查，避免只列名词或公式。明确直接讲解时给完整主线；提示轮只给当前允许的路线和局部帮助，不提前给可反推答案的信息。

用当前回答和有效摘要决定详略：

| 当前证据 | 讲解选择 |
|---|---|
| 一步已正确且理由充分 | 保留其做法，简短通过 |
| 当前首次断在对象或条件 | 先澄清该对象/条件，再继续原路线 |
| 缺必要前置，或连续两次仍卡住 | 补齐最小前提并直接讲清该步，再让用户接下一步 |
| 旧摘要有断点，但当前推理已越过 | 不重贴旧错因，不强制重复练习 |
| 只有选项、没有依据 | 只问一个能诊断的关键理由，等待 |
| 答案与理由已充分 | 简短确认；不为统一格式追加复述或变式 |

这些是教学决策，不是学生界面的固定栏目。只在证据范围适用的具体机制上压缩或展开；证据不足保持该环节未知，当前明确说不懂时针对该步调整。历史中的偏好、效果、自述和独立掌握分别保留证据强度；讲解浓缩不取消原本必须交付的图解。

## 图只帮助看清需要看见的一步

从文字路线中找最值得图解的关系：对象与内容不同、软件与硬件分工、地址到位置的对应、资源归属、事件前后状态、代码对指针或结点的具体修改。选一个聚焦场景，必要时覆盖紧邻的两步，使用户能把中间抽象机制接回文字推理。

例如虚拟地址转换与缺页处理可能需要同一场景中的“先判有效位，再进入相应路径”，但若本题只问页内偏移不变，就不顺带画完整缺页调度过程。一般算式代入、已确认的前提和最终整理留在正文；不是每个解题步骤都生成卡片或动画。

图中能点击的是有角色的对象、关系或事件。展开内容回答局部疑惑，关联高亮帮助辨认去向；必要推理始终在正文可见。具体图形选择见 `dialogue-to-visual.md`，显示和保护合同见 `interactive-delivery.md`。

## 本题解决后，按同一考纲专题展开

取刚结束精确题号或 `local_syllabus_lessons.topic_review_identity`。以本题实际考查的原纲小节为边界。正文一到两句把本题与相关考点串起来。已核本地导图时沿原有分支精选，默认一张树最多四个节点。首屏显示短摘要和同版原纲主考频次，点开才给具体表述与适用的机制简图。纯背景和前置留在原角色。

每个候选都核对具体 `syllabus_ids`、当前 `teaching_boundary` 以及教材页或真题实际考查的 `unit/part_id`。用一条关系说明哪项条件或所求变化使它值得接在本题之后；无独立小点统计时，引用次数须明示对应父考点。同章导航、源图或相似措辞不构成扩展依据。

有同版材料且本轮获准后，调用一次只读交付。 `--withhold-question` 按回执重复传入后继精确 ID。已有会话额外隔离年份时重复传 `--exclude-year`。从同次查询取得 `catalog_sha256` 时传 `--catalog-version`。完全没有后继、额外年份或已读版本时省略对应参数。

```text
python3 scripts/runtime_paths_408.py --run local_quality_408.py render-topic --id <刚结束题/Pxx> --view direct --output <任务可视化目录>/exam-topic.html --inline-root <任务可视化目录>
```

只读检查可将命令换为 `context --topic-review`，省略输出路径。概念讲解可用同一个入口传已核规范点、KSP、原纲 ID 或 `原纲ID#1` 等附列细项身份。用回执 `recap_overview` 写短框架，在同轮放 `visualize_reference`。点开时同时显示考场记忆、知识点记忆和机制图。用生命线、字段、指针、泳道和转移箭头表达实际关系。明确要解释原题时结合原图，公式与必要因果仍在正文。完整索引供用户点名要求时读取。已有个人证据只调整讲解重点。题目仍保护、只问局部或仅查看首答时不用完整专题。小问只允许自己的已公开材料。引用考法不算推荐旧题，真要展示或推荐旧题时继续走实时14天门禁。

字段和报文先对齐本题版式。用[本题快存出图提示词](../../kaoyan-408-wrong-intake/references/output-template.md#按本轮作答取材和出图)的同一结构化入口按实际回答选择位域、控制位或报文。已知参数用本问实际数值及进制，数字来源与本题同版。通用图的符号只用于机制解释。

## 保存真实发生的内容

教学、图解与轻微拓展共同服从当前提示级别。看过、点击过、听懂或提示后完成都不自动升级成独立掌握。按当前 Capture 合同保存实际给出的解释、成品和真实反馈，未讲候选不记为学习事件；不要为新图或拓展另造作答、曝光或掌握记录。

当本问已无已知矛盾、用户能够继续或已明确结束时，沿现有保存/导航合同收尾。保持检查与任务相称，不为同一题循环查库、反复渲染或追加测验。
