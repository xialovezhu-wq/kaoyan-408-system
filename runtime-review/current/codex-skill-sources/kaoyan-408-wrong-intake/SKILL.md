# 完整快速保存

本机路径和解释器先按[共享路径约定](../_shared/kaoyan-408/local-paths.md)定位；下文仓库命令在已定位的项目目录执行，历史回执保留原字节。

Capture是证据容器。使用原生消息和原始附件，不改写或删减对话，不把理解自报、点图或保存成功当成独立掌握。

查询旧经历、准备讲解和检索命中不触发Capture，也不增加学习次数。经历摘要或verified_original_turn片段只能定位既有证据，不能替代本次要求完整封存的消息范围与原附件；仍以原生封存入口的实际验回为准。

快速保存后的新Capture属于待审事实；需定位时才用统一memory catalog/discover加`--include-pending`按Capture或来源精确ID查询。以原生封存回执确认保存，`pending_formal_review` 和 `formal_claim_authority=false` 保留证据边界。讲题沿 question-worker 的当前有界读取。用户明确更正已经正式记录的解释时，交现有正式更正入口保留追加链、使相关旧视图失效并验回。

## 普通单题／年度会话：一次调用

正常快存以20—30秒内交付完整回执、快速总结和可点击考点树为目标，进度文字不算完成。已核题号的 `record` 默认在同一进程完成保存、年度绑定、同版考频和考点树渲染；不用为普通快存另写 JSON。传 `--inline-root` 指定本任务展示目录；省略时只复用当前会话唯一的现有展示目录。已有本轮明确焦点或题设参数时，可用 `--recap-json -` 和 `--recap-output` 调整内容与文件名。详细参数见[输出模板](references/output-template.md)。

正常成功路径复用已验证渲染器及字段模板，不逐题读源码、跑测试、启动浏览器、截图或再次手工改考频。必要的数据、附件、路径和写入校验保留。新改渲染器或真实显示故障才进入开发检查；真实保存故障只恢复失败层，不把开发流程加入每次快存。

已知当前精确题号时：

```text
python3 scripts/runtime_paths_408.py --run mark_study_episode_408.py record --question-id <EXAM408-当前题> --start-anchor '<本题最早用户消息ID或唯一片段>' --end-text '<当前完整保存请求>' --inline-root <任务可视化目录> --compact
```

普通讲解只读；“快速录入”“快速保存”“快速入库”以用户真实原话进入上述操作，收尾后返回学习。

年度专用会话加`--bind-annual`。已授权逐题保存的年度会话明确“下一题”时，带已核验的题号和该参数；普通会话不能仅凭“下一题”封存。程序核对同年同会话后封存、验Capture、绑定并读回年度索引。题号未知时不猜，省略该参数；原生消息和嵌入附件仍完整保存。额外持有的真实原件用重复`--attachment <绝对路径>`。不重写对话或临时拼保存脚本。

程序自动附精确题原图、消息中实际引用的对话图解、本题消息时间范围内的实际3D显示回执及资产。未显示缓存不充作已用图解。没有历史显示回执但确实使用过的旧资产，明确传`--attachment`，不补造记录。

侧栏 Page 作答先用 Page 工具完整读取当前题页面，再在同一次 `record` 加 `--answer-page-id <实际Page ID>`（多页可重复）。入口直接从本会话、本题消息范围的原生 `read_page` 成功回执提取全文和各版块哈希，将首稿与实际读过的修改版一起装入首次封包，并返回 `sidebar_answer_evidence.verified=true`。本轮已完整读过且用户未再编辑时复用；用户说已改或写完后要重新完整读取。缺少指定 Page 的完整回执会在写入前阻断。不要先保存聊天再补侧栏，不抄写代码到临时 JSON，不为普通快存调用补充写者或全账本重建；真实后到的补充仍走原追加合同。

起点必须是本题最早原话。多题同一消息保留原话，用已明确的题号限定处理范围；题号仍不明才问清。保存请求须为原生最新用户消息。若保存前还有必要纠正，先发真实反馈，再加`--feedback-anchor`纳入同次保存。

`--compact`只缩短返回回执，不裁对话或附件。完整快存交付须`capture_verified=true`、`package_verified=true`及`quick_review.status=rendered`、`inline_path_preflight_passed=true`，年度会话还须`annual_binding_verified=true`。同一条 final 实际引用 `quick_review.visualize_reference`，再给后继内容。渲染失败保留已成功的 Capture，按原回执恢复总结；不可仅凭保存成功就结束。

用户明确说“只记录、不总结”时，程序自动跳过树；同义明确请求也可传 `--no-recap`。用户纠正图解形式或要求回复简洁，不取消快存后的考点树。题号尚未核定时不猜，按实际缺项处理。

已保存但年度绑定失败，只用原收据恢复：

```text
python3 scripts/runtime_paths_408.py --run mark_study_episode_408.py verify --receipt <原receipt_ref> --bind-annual --inline-root <任务可视化目录> --compact
```

不新建Capture、不换身份。原生消息或原件缺失时报告具体缺口，不拿摘要降级充作完整原文。

总结失败时，保留成功Capture，用 `verify --receipt <原receipt_ref>` 默认补树；此前有显式总结参数时保留它们。`capture_write_count=0`证明本次只验回与生成。耗时验收区分脚本 `timing_ms.request_total_ms` 和用户发言至完整回复的墙钟时间，不拿脚本毫秒数冒称整轮已达标。

## 当前题的正式入库请求

「将今天快速入库的题全部正式入库」交 [daily-intake-curation](../kaoyan-408-daily-intake-curation/SKILL.md) 处理当天完整范围。单题正式请求先按精确题号、会话和已有回执复用本地 Capture。尚未封存的当前题，沿同一原生标记命令加 `--intent formal`，`--end-text` 取最新明确正式请求原话（如“请把本题正式入库”）；年度会话仍核同年、同题、同线程。`display_status` 是本次用户可见状态。`next_action=continue_local_formal_intake` 表示证据已就绪：在同一任务接 kaoyan-408-enhancement-intake，以返回的 Capture 身份和原学习日期完成双 API 质量校验、正式编纂、唯一写入和读回。封存回执只证明证据已保存。仅快存则在速记与回执后结束。兼容的 `awaiting_web_enhancement` 是账本状态名，不能据此让用户上传回包。

## 快速入库后的专题复习

快存后的相关节点要能直接复习实际考法。涉及公式时展示公式、符号含义、条件和单位，并给沿已核真题步骤改换数字的演算例，标为改编示例。编码节点使用真实位格、位首与位中跳变的波形，可逐位核对；不能用“编码与调制”分类框图替代差分曼彻斯特解码。自动快存同样交付简短回顾和考点树。

数据通路节点按当前真题连接图展示部件、数据方向、各拍驱动源、暂存值和控制信号。Y/Z 单总线题使用已绑定的逐拍专图；不能用寄存器读口、立即数、多路选择的通用框图代替。结果暂存与输出使能分开显示，关闭输出仍保留寄存值。

验回后，同一条 final 按回执、简短框架、可点击考点树、后继题顺序交付。普通“快速入库／快速保存”包含此总结；只有用户明确要求“只记录、不总结／不讲解”等省略总结时才只回保存结果。采用回执的 `quick_review.identity`，旧回执只用已经独立核实的刚结束题身份。绝不拿 `next_display` 当复习题。

- 本题已解决且复习范围获准时，按[现有专题入口](../kaoyan-408-question-worker/references/exam-oriented-teaching-flow.md)读取同版考点树，传回执里的 `withhold_questions` 和会话真实隔离年份。正文一到两句交代本题切入和相邻考点框架。首屏最多四个考点节点，直接标主考频次。点击后只显示选中点的简短复习。
- 一次调用入口会在精确题因整年保护被拦截时，按该题已核考点生成知识点总结，保留原题身份与年份保护。不要另外手动换题、改年份或重新调用保存。若返回 `capture_saved_recap_pending`，按原回执只补总结。
- 生成前把刚验回的精确题号或 Pxx 与同版题面、已读本题备课材料、本轮真实作答核对。用本轮已经说清的步骤或第一个真实卡点选择考点、字段或报文，用题面和备课核定字段值。首答充分正确就突出所验证的条件。没有理由证据时只说明当前核对项。按[本题快存出图提示词](references/output-template.md#按本轮作答取材和出图)把重点传给 `render-topic --case-context -`。同题重做时也以本轮回答重新选。
- 考场记忆和知识点记忆共用节点详情，配实际机制图。时间先后画生命线或泳道，地址字段画映射箭头，数据结构画结点、指针或存储格。前者提炼一个考法的题面线索与起手，后者写通用规则及必要条件或易混边界。核实的变式用当前规范点身份。来源未知时只按本轮已核考点取材。按需深入时才读取完整专题资料。
- 固定报文或编码用一个外框、同一把位标尺、字段起止位置及位宽，区分固定首部、可选区、数据和尾部。本题有原图时保留其版本、行列和字段。三次握手沿实际端点、报文编号与方向标本题已核 SEQ 和 ACK，保留原进制。本问只放已给字段和获准推导，下一小问的值和可反推步骤在渲染前排除。
- `current_disclosed_only=true`、未解、提示阶段或用户限定范围时只复述已经公开的局部与成立条件。快存本身不给答案授权。兄弟小问和后继题在读取及渲染前隔离。找不到精确身份或同版资料时说明实际缺口，按本轮真实证据给能迁移的局部。
- 公式留在聊天正文。按现有交互入口复用贴本轮的局部图或同轮专题。无图一行事实可简述。视觉或专题读取失败按实际状态报告，已保存的回执可直接复用。保存后新出的复习属于当轮交付，不追加或重放 Capture。
