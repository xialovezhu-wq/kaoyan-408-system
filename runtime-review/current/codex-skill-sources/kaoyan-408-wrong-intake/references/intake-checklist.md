# Complete conversation package checklist

## Learner turn

- [ ] Use one validated current surface and controlled grader.
- [ ] Freeze feedback before persistence.
- [ ] Non-terminal managed turns remain one private draft with zero Capture/pending.
- [ ] A managed terminal or explicitly authorized standalone quick intake binds one
      sealed final package ID and exactly one durably reopened Capture.
- [ ] Store complete question/options, all ordered user/assistant turns, frozen
      feedback, later corrections, and all currently available original attachments.
- [ ] New traces are complete; no 24-event or 32-KiB first/last truncation.
- [ ] Missing evidence remains in `missing_fields`; later attachment supplements are
      allowed.
- [ ] The fast path writes only
      `<package-root>`.
- [ ] A verified current Capture awaits local enhancement; legacy `awaiting_sol_formalization` rows follow the contract that created them.
- [ ] No child model, background handoff, producer attestation, consumer, report,
      adoption, T9-Data write, or formal write occurs.
- [ ] Feedback, same-display correction, recovery, and navigation frontier remain
      receipt-bound.

## Explicit formal turn

- [ ] Freeze one exact dated or explicit package set and capture-set SHA.
- [ ] Reopen local conversation/source/attachments and verify every manifest row.
- [ ] Ultra routes native reads directly; non-Ultra first invokes the existing
      orchestrate Skill when at least two independent reads exist.
- [ ] Any native child is a read-only Luna Max Fast leaf returning to the same Sol.
- [ ] Sol seals a direct-evidence decision before serial batch-size-1 writer work.
- [ ] RepoLock, WAL, receipt, postcommit, mark-result and terminal binding all pass.
- [ ] Proven COMMITTED work is never reapplied.
- [ ] Completed terminal outcomes archive only after T9 sentinel, tree/manifest,
      locator-note and receipt verification.
- [ ] `needs_user|failed` retains the complete local package.
- [ ] Archive failure is `FORMAL_COMMITTED_ARCHIVE_PENDING` and resumes archive only.
