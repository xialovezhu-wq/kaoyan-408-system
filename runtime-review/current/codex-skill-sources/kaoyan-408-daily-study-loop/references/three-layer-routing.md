# 408 evidence surfaces

Use this map only when the request spans systems.

| Surface | Owns | Does not own |
|---|---|---|
| 408 formal repository | answer-safe nodes, taxonomy, relations, review metadata | complete stems, answers, images, detailed solutions |
| 408 details system | protected question context, images, solution detail, handwriting | formal graph truth or learning mastery |
| StudyVault/Tutor | study notes, recall sessions, diagnostic learning interaction | formal intake facts or repository writes |
| LLM Wiki | durable knowledge synthesis and provenance | user-specific wrong-question truth |
| Second brain/dashboard | process status and cross-system summaries | specialist formal records |

Choose the surface from the requested outcome. Do not mirror content merely because
two surfaces exist. Cross-surface handoffs carry a compact summary, provenance, and
boundary note rather than protected source content.
