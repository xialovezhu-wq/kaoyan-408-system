# 408 左侧 HTML 讲解

给当前题或独立小问作实质讲解、获准复盘或交付晚间阅读页时，只要有图，在同一轮打开本聊天的**左侧 HTML 页**。右侧写本轮文字答案、必要条件和原生公式，附该页普通文件链接。图、时间轴、对象卡和三维控件留在左页。静态图也放入页面。普通出题仍按原合同给题面，等真实首答。只记录、备课和纯文字请求沿各自入口。

## 取本轮页面

- 先按原入口核本问、来源版本、view 和提示级。提示页只含当轮已允许的状态，完整解法须已获准。文件名、标题、隐藏区域、脚本数据和 ARIA 也在这一范围。切题或收窄权限时先将本任务的旧答案页切到新题面或收起。在同一范围复用打开的页，保留当前步进位置。
- 普通实时渲染一次调用原入口和侧栏包装。用 `python3 scripts/runtime_paths_408.py --run sidebar_visual_408.py --render <现有渲染器及参数> --inline-root "<本聊天可视化目录>"`。如已取得 `sidebar`，直接用该回执打开。阶段私有的准备操作仍用各自原入口。
- 新快存用 `quick_review.sidebar`。晚间阅读用 `sidebar`。普通讲题、晨间 D、专项、年度课件、专题复盘或 A2UI 先取该阶段的学生图。渲染回执里的 `path` 指向已过滤的 HTML 片段时，将该回执交下方入口，原片段字节原样进入独立页面。年度回执取其中的 `visual`，其他嵌套结果取本图那一层。已备整页按原访问范围和资产位置使用。教师 JSON 和私有解法继续留在讲解入口。

```sh
python3 scripts/sidebar_visual_408.py --receipt - --root "<当前聊天的可视化目录>" --title "<该阶段可公开的题号和页名>"
python3 scripts/sidebar_visual_408.py --html "<本阶段已验学生HTML>" --sha256 "<同份交接中的SHA256>" --root "<当前聊天的可视化目录>" --title "<公开页名>"
```

- 三维仍按本次困难及预制课件选取。把原教学决定交 `python3 scripts/sidebar_visual_408.py --spatial-context - --root "<当前聊天的可视化目录>"`。它沿本机分派核对精确题目、允许阶段及版本，装入该阶段的场景和对象卡，返回 `sidebar`。只有本轮另点 iPad 才用专用投屏入口。查看和旋转不产生作答记录。

## 打开并确认左右位置

1. 始终在发起本轮学习的**当前聊天原窗口**打开。该窗在主屏、中间、右侧或 iPad 时也已获长期授权，无须移到最左屏或另开同聊副本。只操作这个聊天的文件标签、分栏和停靠。打开侧栏的授权与独立 iPad 投屏是两件事。
2. 实际调用 `mcp__codex_app__open_in_codex`，参数取页面回执的 `open_arguments`（本地 HTML 绝对路径，类型为 `file`）。省略 `threadId` 和 `placement`，发给调用聊天。若当前布局把聊天浮在图上，选择「停靠聊天 → 移至右侧窗格」，左侧留给网页。
3. 用 `python3 scripts/sidebar_visual_408.py --show-page "<本页绝对路径>" --window-title "<本聊天的确切标题>" --link-label "<本轮贴出的链接文字>"` 读回实际文件 URL 和两侧位置。命令只在本聊天操作。仅当同聊有多个窗口时可加 `--origin-display "<发起窗口实际所在的显示器>"` 消歧。平常不指定物理屏。已在正确布局时直接复用。
4. `queued` 只说明宿主排队。若收到 `link_needed` 或宿主模块加载失败，同轮在当前聊天随已核学习文字发出本图普通链接，再用上述命令代为点开。仍有显示问题时可在发起窗口的原生浏览器标签打开同一 HTML 并停靠右侧聊天。只在当前窗口处理。不能实证时交付同范围文字和可重开的链接，如实报显示状态。
5. 右栏使用该页普通 Markdown 链接及独立可读的文字；图、控件与对象明细在左页。只有读回文件在左、聊天在右才称已打开。显示恢复沿原回执，不重放学习或保存。
