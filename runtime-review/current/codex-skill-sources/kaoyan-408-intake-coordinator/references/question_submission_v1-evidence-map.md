# Retired question_submission_v1 evidence map

This is a read-only historical reference for artifacts created before 2026-07-12.
In inspection-only use it is not an executable workflow: never create, revise,
submit, wake, cancel, or requeue one of these objects. A separately authorized,
fenced cancellation follows `coordinator_contract.md`, not this evidence map.

An old artifact may identify:

- `job_id` and schema version;
- evidence inbox and manifest paths;
- source, attachment, and details locators;
- answer-safe candidate metadata;
- submission, approved, or manifest hashes;
- queue state, claim history, transaction ID, journal, and receipt paths.

Treat paths and identifiers as locators, not proof. Verify the named fields from
disk. Do not expose answer-bearing files or copy protected payloads into output.

For inspection-only output, report the named artifact, files that actually exist,
recorded state, available hashes, transaction/journal/receipt presence, and any
binding conflict. State that the workflow is retired and perform zero mutations.
