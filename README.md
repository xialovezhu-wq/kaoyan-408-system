# 考研 408 学习系统

面向数据结构、计算机组成原理、操作系统和计算机网络的本地学习工作流。系统把真实试题来源、逐题学习证据、错题节点、知识点摘要和复习调度分开管理，并以明确的身份与回执连接各环节。

## 运行逻辑

1. 晨间准备从已核验的真题候选中导出一个网页选题输入，当前新流程目标为 30 道题。按精确题面执行七天曝光门禁，优先较久未接触的题，并保持已经开始或暂停的会话合同。
2. 已发布题通过 `learning_turn_408.py` 提交真实消息与当前展示回执；非终态继续同题，终态封存完整 Capture 后才推进。固定入口可同次返回一次有界知识点教学摘要。
3. 普通单题使用独立入口保存完整学习证据。快速 Capture 只保存事实、曝光和进度；新合同下的正式判分、FSRS 与长期个人摘要留给网页增强回包的正式入库。
4. `enhancement_intake_408.py` 处理明确集合的增强包；正式写者负责校验、幂等、事务和回执，恢复时只补未完成的提交后步骤。
5. 知识点摘要只读服务日常讲题；掌握度或调度不能从“讲过”“看懂”自动推定。来源、题面身份与未公开答案始终独立保护。

## 目录

| 目录 | 用途 |
|---|---|
| `scripts/` | 晨间准备、学习入口、Capture、正式写者、调度、来源校验、归档和导航 |
| `schema/` | 各版本请求、事件、回执与状态合同，以及默认关闭的策略模板 |
| `codex-skill-sources/` | 当前学习、快速保存、晨间准备和正式入库技能合同 |
| `tests/` | 有界 JSONL 索引与 Capture 提交索引的合成测试 |
| `examples/` | 专门生成的无个人数据结构示例 |

真实运行会使用节点总表、知识点库、题库来源、详情图、Capture 账本和 runtime 状态。它们属于使用者自己的私有数据，不在此仓库中。

## 环境与入口

建议 Python 3.11 及以上。基础逻辑以标准库为主；题图校验与预处理需要 Pillow，晨间 FSRS 调度依赖 `requirements-morning-coverage.txt` 中的 `fsrs==6.3.2`，DOCX 导入需要 python-docx。Swift OCR 需要 macOS 系统框架。Obsidian、题图详情库、共享发布器、外部归档与模型端由使用者自行配置。

在仓库根目录只读查看接口：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 scripts/learning_turn_408.py --help
PYTHONDONTWRITEBYTECODE=1 python3 scripts/standalone_question_intake_408.py --help
PYTHONDONTWRITEBYTECODE=1 python3 scripts/enhancement_intake_408.py --help
PYTHONDONTWRITEBYTECODE=1 python3 scripts/export_morning_input_408.py --help
```

学习入口要求已核验的展示回执、合法的消息来源和隔离的 runtime；空仓库不能直接开始晨间学习。先依据 schema 配置自己的私有库、题源与生产绑定，再在隔离环境试用。现有代码包含历史兼容和修复入口，不能把旧流程的语义套到新晨间合同。

## 公开范围与个人数据边界

本仓库从本地学习系统单独导出，只包含通用源码、数据结构、当前工作流合同和少量合成测试。原仓库的 Git 历史没有迁入。

真实题卡、首次作答、完整对话、个人知识点摘要、复习记录、分数、调度状态、Capture 包、原始附件、书籍教材和外部归档均不公开。`examples/` 是本次专门编写的合成结构示例，不能作为真实学习证据提交。

源码中的本机用户路径已改为 `/Users/your-user`；归档磁盘 UUID 改为全零占位；原账号的私有库名称不作为默认远端。涉及 Study-Pro-Bridge、Obsidian、MarginNote、Codex 会话库和外部磁盘的集成功能需要使用者自行配置。不要把真实学习目录直接作为这个公开仓库的工作目录。

公开版未携带个人生产绑定描述符，需要在自己的隔离环境生成对应绑定；历史迁移脚本的个人修复清单已清空，保留通用实现。技能文件是工作流参考，不会自动安装或执行。原系统的旧协议保留用于理解和恢复逻辑，不能替代下文所列当前入口。

## 验证情况

发布准备进行了全部 Python 文件的 `ast.parse` 语法检查、全部 JSON 文件解析、下列入口的 `--help` 检查及 Gitleaks 源码扫描。没有执行真实学习写入、正式入库、归档或云端发布；没有运行需要完整私有库与外部应用的端到端流程。

`tests/` 仅保留已检查为临时目录和合成数据的测试子集；没有宣称完整测试套件通过。

## 公开版的发布边界

本公开副本不默认向原三科完整私库上传。原账号远端已替换为 `YOUR_GITHUB_ACCOUNT` 占位，本机集成路径已替换为 `/Users/your-user`，生产共享发布器和私有运行配置没有打包进入此仓库。上面的 `--help` 命令只显示接口，不执行学习写入或上传。后续若自行接入发布器，须先明确设置自己的目标目录、远端和公开范围；公开源码仓库与真实学习数据目录应分别维护。
